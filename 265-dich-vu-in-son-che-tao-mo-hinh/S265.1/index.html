Tip 1 — Gửi file STL "watertight"

File kín khít (watertight) in ngay được; file hở mesh xưởng sửa miễn phí nhưng mất 1–2 giờ. Muốn nhanh, xuất file ở độ phân giải cao thay vì bản preview.

Tip 2 — Chọn tỉ lệ theo không gian trưng bày

Đo sẵn chỗ đặt mô hình: rộng 60cm tương ứng khu 1:500 khoảng 30 ha. Để chật hoặc chổng chân đế là mất công làm lại đế.

Tip 3 — Sơn mẫu thử màu trước

Với figurine sưu tầm, xưởng sơn 1 bộ phận nhỏ (đầu/vũ khí) theo bảng màu chốt — bạn duyệt rồi mới sơn toàn thân, tránh lệch tông cả mô hình.
